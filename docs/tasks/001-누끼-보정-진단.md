# 지시서 001 — 실제 상품 사진 9장으로 누끼·보정 현황 진단 (코드 수정 전)

작성: 온라인 파트 팀장(Claude 채팅) / 담당: 개발 팀장(Claude Code) / 작성일: 2026-11-23

## 목적
앱이 실제 매장 사진에서 어디까지 되고 어디서 막히는지를 **코드를 고치기 전에** 확인합니다. 결과를 보고 002번 개선 지시서를 씁니다.

## 입력
- 상품 1개(분홍 후드 헨리넥 니트, 2버튼, 드로스트링)의 원본 사진 9장. 사장님 PC에 있으며 파일명은 `KakaoTalk_20261114_153845918.jpg`, `…_01.jpg` ~ `…_08.jpg`입니다. 위치를 모르면 사장님께 묻습니다.
- 컷 구성: 옷걸이 정면 1, 마네킹 정면 전체 2(후드 내림), 마네킹 후드 올림 정면 1, 마네킹 측면 1, 마네킹 후면 1, 상단·목 클로즈업 2, 하단 클로즈업 1.

## 사진에서 이미 보이는 문제 (확인 대상)
1. 마네킹: 금색 꼭지(피니얼)와 목 받침이 옷 위로 보입니다. 마네킹 목 부위에 갈색 얼룩이 있습니다. 하단에 검은 받침대 기둥이 보입니다.
2. 옷걸이 컷: 벽에 붙은 투명 걸이 부품이 옷걸이 위에 있습니다.
3. 구김: 배·허리 부분에 대각선 주름과 그림자가 크게 있고, 후드 뒷면과 소매에도 있습니다.
4. 색감: 같은 옷인데 컷마다 분홍색이 다르게 보입니다(옷걸이 컷은 더 탁한 장미색, 후면 컷은 더 밝은 살구빛 분홍).
5. 배경: 흰 벽돌 벽, 왼쪽 회색 캐비닛 패널, 오른쪽 문과 손잡이가 컷마다 다르게 보입니다.

## 할 일
1. 9장을 현재 앱으로 돌립니다. 무료 방식 우선(BiRefNet 누끼, 받침대 제거, IOPaint). **Photoroom 등 유료 호출은 사장님 승인 전까지 하지 않습니다.**
2. 컷마다 아래를 기록합니다.
   - 누끼가 옷 가장자리를 잘 따는지(후드 안쪽, 끈, 소매 틈, 단추)
   - 마네킹의 금색 꼭지·목·받침대가 남는지
   - 얼룩 자동 찾기가 마네킹 얼룩을 잡는지, 옷 디자인(리브, 봉제선)을 잘못 잡는지
   - 구김이 얼마나 펴지는지, 니트 질감이 뭉개지지 않는지
   - 색감 통일이 컷 사이 분홍 차이를 줄이는지
3. 원본과 결과를 **나란히 놓은 비교 이미지**(컷마다 1장 또는 한 장짜리 시트)를 만듭니다.
4. 코드는 고치지 않습니다. 버그를 발견하면 보고서에 적기만 합니다.
