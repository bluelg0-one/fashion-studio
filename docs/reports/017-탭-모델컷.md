## 0. 사장님이 해 주셔야 할 일 (먼저 읽어 주세요)

돈·계정이 걸린 일이라 앱이 대신하지 않습니다. Vercel 환경변수는 제가 바꾸지 않았습니다.

**FASHN (지금 있는 엔진)**
- Vercel → 프로젝트 → Settings → Environment Variables에 `FASHN_API_KEY`(FASHN 대시보드의 API 키)를 넣고 다시 배포합니다.
- 키가 없으면 모델컷 탭 위에 "모델컷을 만들려면 Vercel에 FASHN_API_KEY가 필요합니다"가 뜨고, 생성 버튼이 꺼집니다.

**Google 가상 피팅 (새로 추가, 사장님 승인 건)**
1. Google Cloud 콘솔(console.cloud.google.com)에서 프로젝트를 만들거나 고르고, **결제 계정을 연결**합니다(유료).
2. 'API 및 서비스'에서 **Vertex AI API**(aiplatform.googleapis.com)를 '사용'으로 켭니다.
3. 'IAM 및 관리자 → 서비스 계정'에서 서비스 계정을 하나 만듭니다.
   - 역할은 **Vertex AI 사용자**(`roles/aiplatform.user`) 하나면 됩니다.
   - 만든 계정의 '키' 탭에서 **JSON 키**를 만들어 내려받습니다.
   - 이 파일은 비밀번호와 같습니다. 채팅·메일·저장소에 올리지 마세요.
4. Vercel 환경변수에 아래를 넣고 다시 배포합니다.

| 이름 | 값 | 필수 |
|---|---|---|
| `GOOGLE_VTO_CREDENTIALS` | 내려받은 JSON 키 파일 **내용 전체**(중괄호 `{`부터 `}`까지) | 필수 |
| `GOOGLE_CLOUD_PROJECT` | 프로젝트 ID(콘솔 맨 위 프로젝트 선택 창에 보이는 ID) | 필수 |
| `GOOGLE_CLOUD_LOCATION` | 지역. 비우면 `us-central1` | 선택 |
| `GOOGLE_VTO_MODEL` | 모델 이름. 비우면 `virtual-try-on-001` | 선택 |

- 넣지 않으면 모델컷 탭에서 Google 선택지가 꺼지고, 필요한 변수 이름이 안내됩니다.
- **주의(미확인)**: 검색 결과 요약에 `virtual-try-on-001`의 지원 종료 예정일이 2026-09-14로 나와 있었습니다(서비스 중단은 2027-03-15). 오늘 날짜(2026-11-26) 기준으로 이미 지났을 수 있습니다. 첫 시험에서 '모델 없음' 오류가 나면 콘솔의 Vertex AI 모델 목록에서 새 가상 피팅 모델 이름을 찾아 `GOOGLE_VTO_MODEL`에 넣어 주세요. 코드를 고칠 필요는 없습니다.
- Google 가상 피팅은 **사람 사진 + 옷 사진**을 받아 입힌 사진을 만듭니다(모델을 새로 만들지 않음). 그래서 '기본 모델 사진'이 구도별로 1장씩 필요합니다.
  - 구도는 상반신(얼굴 없음) / 하반신 / 원피스(어깨~밑단) 세 가지입니다.
  - 모델컷 탭에서 직접 올리거나, FASHN 결과 카드의 'Google 기본 모델로 저장'을 누르면 됩니다.
  - 이 사진은 이 브라우저에만 저장되고 저장소에 올라가지 않습니다.

## 4. 아직 안 된 것·위험한 점

- **실제 FASHN·Google로는 실행해 보지 않았습니다.** 다음은 아직 모릅니다.
  - 구도 지시가 실제로 얼굴을 빼 주는지
  - Google 응답 모양이 위 형식과 같은지
  - 모델 이름이 아직 유효한지
- 첫 실제 시험은 사장님이 키를 넣은 뒤 1장씩 해 보시기를 권합니다.
- 자동 자르기는 피부색으로만 얼굴을 찾습니다. 다음 경우에는 틀릴 수 있어서, 자른 경우는 항상 '확인 필요'입니다.
  - 피부색과 비슷한 옷(베이지·누드톤)
  - 머리카락이 얼굴을 가린 경우
  - 강한 조명
- 비용 기록의 모델컷 금액은 **추정**입니다(FASHN 장당 크레딧 수 미확인).
- Google 기본 모델 사진은 이 브라우저(localStorage)에만 있어, 다른 PC에서는 다시 넣어야 합니다.
- 모델컷 사진은 상품 데이터에 들어가므로, 모델컷 1장마다 상품 저장 크기가 약 0.3~1MB 늘어납니다.
- 채널 내보내기·인스타·쇼피에는 모델컷을 넣지 않았습니다(지시 범위 밖). 쓰려면 'AI 생성' 표시 정책부터 정해야 합니다.
