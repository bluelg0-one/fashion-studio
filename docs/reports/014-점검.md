- 기준: `claude/hanger-v2` = acb495a (013까지 합쳐진 앱), 2026-11-26
- 방식: '필요한 만큼만' 원칙입니다. 새로 만들기보다 지금 코드를 그대로 쓰고, 마네킹 전용은 **지우지 않고 화면에서만 숨깁니다**.

## C. 버그·위험

| 순위 | 무엇 | 쉬운 설명 | 대책(1단계에서) |
|---|---|---|---|
| 1 | **상품을 열 때 '자동으로 만든 디테일컷'을 지움** | 예전 규칙이 원본이 없는 디테일컷(`derived`)을 지움. v2의 자동 디테일컷이 상품을 다시 열 때마다 사라짐 | v2 디테일컷은 새 표시(어느 사진·어느 상자에서 잘랐는지)를 달아 지우지 않게 함 |
| 2 | 받침대 지우기가 기본으로 켜져 있음 | 옷걸이 사진 맨 아래의 좁고 어두운 끈·고리·바지 끝단을 받침대 기둥으로 보고 지울 수 있음(실제 사진으로는 확인 못 함) | v2 기본값에서 끔 |
| 3 | 꼭지 위 정리(`clearAboveFinial`)가 기본으로 켜져 있음 | 금색·놋쇠 옷걸이 고리를 마네킹 꼭지로 보면, 그 위의 고리 끝을 지울 수 있음 | v2에서는 끔 |
| 4 | 자동 분류 지시문이 마네킹·10종 컷 기준 | 옷걸이 정면·후면을 '측면'·'확대'로 잘못 나눌 수 있음 | v2 지시문: 정면/후면/확인 필요만 |
| 5 | 확대 컷 판단을 '자동 수평 허용 컷'과 같은 표로 함(`autoLevelAllowed`) | 둘은 뜻이 다른데 한 표를 같이 씀. v2에서 컷 이름이 바뀌면 함께 틀어질 수 있음 | v2 정면·후면을 '전체 컷'으로 명시 |
| 6 | 상품 데이터에 사진을 data URL로 통째로 저장 | 한 컷에 버전 6개 × (누끼·1차·2차)를 저장해, 상품이 늘면 브라우저 저장 한도에 닿을 수 있음 | v2는 컷 수가 2장이라 줄어듦. 이번에는 그대로 둠 |
| 7 | `studio-drive.mjs` 화면 검사는 예전부터 실패 | 드라이브 화면 검사가 원래 통과하지 않음(실제 드라이브는 모의로도 확인 못 함) | 이번 범위 밖, 기록만 |
