# 지시서 012 보고 — 인스타 게시: 두 종류 토큰 모두 지원

작성: 2026-11-24 · 브랜치 `claude/integration-002`

## ① 무엇이 되는지
- '연결 확인'에서 난 오류("Invalid OAuth access token - Cannot parse access token")는 사장님 토큰(EA로 시작, Facebook 계열)을 Instagram 전용 주소(graph.instagram.com)로 보내서 생긴 것으로 보입니다. **이제 토큰 앞부분을 보고 주소를 자동으로 고릅니다.**
  - `IG…`(Instagram 로그인 토큰) → `graph.instagram.com/v25.0`(예전과 같음)
  - `EA…`(Facebook·Meta 비즈니스 토큰, 시스템 사용자 토큰) → `graph.facebook.com/v25.0`
  - Vercel 환경변수 `INSTAGRAM_GRAPH_HOST`로 직접 정할 수도 있습니다(`graph.instagram.com` 또는 `graph.facebook.com`만 허용).
- **`INSTAGRAM_USER_ID`**(인스타 비즈니스 계정 ID, 숫자, 비밀 아님)
  - 있으면 `/me`를 부르지 않고 그 ID로 계정 이름 확인·게시·24시간 게시 횟수를 부릅니다(`/{id}/media`, `/{id}/media_publish`, `/{id}/content_publishing_limit`).
  - Facebook 토큰인데 ID가 없으면, '연결 확인'에서 인스타에 요청하지 않고 바로 "INSTAGRAM_USER_ID가 필요합니다…"라고 안내합니다.
- 토큰을 붙여 넣을 때 섞인 앞뒤 공백·따옴표·줄바꿈, 'Bearer ' 머리말은 자동으로 잘라 냅니다.
- '연결 확인' 결과에 계정 이름, 방식(예: 'Facebook(Meta 비즈니스) 토큰'), 주소(graph.facebook.com), 계정 ID 출처만 보입니다. **토큰 값은 응답·오류 문구에 넣지 않습니다**(인스타 오류 문구에 토큰이 섞여 오면 ***로 가림).

## ② 테스트 결과
- `npm test` **123개 모두 통과**(새로 5개). 모두 모의 응답이고 실제 인스타그램·Meta는 부르지 않았습니다.
  - 토큰 정리(공백·따옴표·줄바꿈·Bearer)
  - IG 토큰 → graph.instagram.com + `/me`
  - EA 토큰 + ID → graph.facebook.com, `/me` 없이 ID로 확인·게시
  - EA 토큰인데 ID 없음 → 안내(요청 0회)
  - 호스트 강제 지정·허용 목록, ID 숫자 확인, 오류 문구에서 토큰 가림
  - 기존 검사의 '연결 확인' 기대값(방식·주소 추가)도 고쳤습니다.
- `npm run build` 통과.
- 브라우저 검사 `tests/studio-instagram.mjs` 통과: '연결 확인' 뒤 '방식: Facebook(Meta 비즈니스) 토큰 (graph.facebook.com)' 표시를 추가로 확인했습니다.

## ③ 아직 안 된 것·위험한 점
- **실제 Meta 서버로는 확인하지 않았습니다.** 시스템 사용자 토큰에 인스타 게시 권한(instagram_basic, instagram_content_publish 등)과 해당 인스타 계정·페이지 연결이 되어 있어야 게시됩니다. 권한이 없으면 '게시 권한이 없습니다' 안내가 나옵니다.
- Graph API 버전(v25.0)은 기존 코드와 같게 두었습니다.

## ④ 사장님이 해 주셔야 할 일
1. Vercel 환경변수에 **`INSTAGRAM_USER_ID`**를 추가합니다(wooahshop의 인스타 비즈니스 계정 ID, 숫자). Meta 비즈니스 설정이나 Graph API 탐색기에서 연결된 인스타 계정의 ID로 확인할 수 있습니다.
2. 다시 배포한 뒤 '연결 확인'을 눌러, '@wooahshop · 방식: Facebook(Meta 비즈니스) 토큰 (graph.facebook.com)'이 보이는지 확인해 주세요.
