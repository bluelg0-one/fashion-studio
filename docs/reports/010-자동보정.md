# 지시서 010 보고 — 상품 단위 자동 보정

작성: 2026-11-24 · 브랜치 `claude/integration-002`

## ① 무엇이 되는지 (화면에서 해 볼 방법)

### 시작하는 곳 (두 군데)
- 상품 선택 줄 아래 새 **‘자동 보정’** 칸 → **‘자동 보정할 상품 고르기’**를 펼쳐 상품에 체크(모두 선택 가능) → **‘자동 보정 준비 (예상 보기)’**
- 드라이브 가져오기가 끝난 화면 → **‘자동 보정 시작 (가져온 상품 n개)’**(가져온 상품이 자동으로 골라짐)

### 시작 전에 보이는 것
- 상품 수, 컷 수(이미 보정한 컷은 ‘n개 건너뜀’)
- **예상 시간**(BiRefNet 장당 약 30초 + 2차 약 30초 기준)
- **예상 Claude 비용**(컷당 ‘적극’ 4회): 예) 4컷이면 약 $0.11~$0.64
- 유료 대체 켜짐/꺼짐과 상한
- 무료 엔진 상태(BiRefNet·IOPaint)

**‘시작’을 눌러야 진행됩니다.** 무료 엔진이 꺼져 있으면 **‘사장님 PC에서 바탕화면의 IOPaint Start를 켜 주세요’**가 뜨고 ‘시작’이 잠깁니다.

### 처리 순서 (상품마다, 대표 정면 먼저)
1. 자동 수평
2. **1차**: 무료 BiRefNet 누끼 + 받침대 + 정리 + 색상 기본값(밝기 +20, 화사하게 +30)
3. **색감 통일**: 대표 정면의 옷 색 기준. 그 상품의 ‘색감 기준’으로도 저장되어, 나중에 고치는 컷도 같은 색감으로 맞춰집니다.
4. **2차**: Claude 찾기 ‘적극’(4타일) → 작은 상자 분할 → 무료 IOPaint로 한 번에 지우기
5. **최종 확정**

모두 지금 앱 기본값 그대로이고, 각 단계는 새 버전으로 저장되어 컷마다 **‘이전으로’(무료)로 되돌릴 수 있습니다.**

### 엔진 정책
- 처리 중 사장님 PC의 무료 엔진이 끊기면 그 컷이 **‘대기(PC 연결 끊김)’**로 바뀝니다. **다음 컷으로 넘어가지 않고 기다렸다가**, 다시 켜지면(5초마다 확인) 같은 단계부터 이어서 합니다.
  - IOPaint는 Claude를 부르기 **전에** 확인해서, 꺼져 있을 때 Claude 비용만 나가는 일을 막았습니다.
- **‘무료 엔진이 안 될 때 유료(Photoroom)로 대신 처리’**는 기본 꺼짐입니다.
  - 켜면 **이번 작업 유료 상한($)**을 입력합니다(기본 $2).
  - 끊긴 단계만 Photoroom(누끼, 또는 2차는 다림질. 얼룩 AI는 쓰지 않음, $0.10/회)으로 대신하고, **상한을 넘기 전에 멈춥니다.**
  - 유료로 처리한 컷은 ‘확인 필요’로 표시합니다.

### 진행 화면
- 상품별 줄에 컷마다 상태 표시: 대기 / 처리 중 / 대기(PC 연결 끊김) / 완료 / 확인 필요 / 실패 / 건너뜀
- 진행 막대, 남은 예상 시간(끝난 컷의 실제 평균), ‘중단’ 버튼
- 중단하거나 창을 닫아도 단계마다 저장되어, **‘이어서 하기’**를 누르면 끝난 단계는 다시 하지 않습니다(Claude 비용도 다시 들지 않음).
- 이미 보정한 컷은 건너뛰는 것이 기본입니다. **‘이미 보정한 컷도 다시 보정’**을 켜면 처음부터 합니다.
- 한 컷이 실패해도 나머지는 계속합니다.

### 품질 안전장치 → ‘⚠ 확인 필요’ 목록 (컷마다 이유 표시, ‘상품 열기’로 이동)
- 누끼 옷 면적이 사진의 **5% 미만**(옷이 지워졌을 수 있음) 또는 **85% 초과**(배경이 남았을 수 있음)
- 자동 수평 **신뢰도 25% 미만**
- Claude가 찾은 곳 **0곳** 또는 **40곳 이상**
- 색감 통일 후에도 대표 컷과 색 차이 **ΔE 10 초과**
- 유료 대체로 처리한 단계

### 끝나면 요약
완료·확인 필요·실패·건너뜀 수, 쓴 비용(Claude·유료), 걸린 시간, 확인 필요 목록, 실패 목록. 모든 비용은 ‘비용 통계’에도 남습니다.

### 다음 단계에서 쓰기
화면과 분리된 함수입니다: `src/utils/autoPipeline.js`의 `planAuto`·`runAuto`. 실제 처리는 `AutoStudio.jsx`의 `autoSteps`가 저장된 상품 데이터로 합니다. 다음 단계(상세페이지 자동 제작 등)에서 버튼 없이 이어 부를 수 있습니다.

## ③ 아직 안 된 것·위험한 점

- **실제 사진으로 자동 보정 품질을 아직 보지 않았습니다.** 모의 사진(단색 사각형)으로 순서·저장·대기·비용만 확인했습니다.
  - BiRefNet은 이 환경에서 모델(약 450MB)을 받을 수 없어 모의 응답으로 검사했습니다.
  - IOPaint는 진짜로 돌렸지만 모의 사진이라 지우기 품질은 판단할 수 없습니다.
- **품질 기준 숫자는 처음 정한 값**(면적 5%·85%, 수평 25%, ΔE 10, 40곳)입니다. 실제 사진에서 ‘확인 필요’가 너무 많거나 적으면 조정이 필요합니다.
- **2차는 Claude가 찾은 곳 중 신뢰도 0.3 이상을 사장님 확인 없이 바로 지웁니다**(기존 화면에서는 사장님이 확인 후 지움).
  - 각 단계가 버전으로 남아 ‘이전으로’로 되돌릴 수 있지만, 디자인 요소를 잘못 지울 위험이 있습니다.
  - 그래서 결과를 원본과 비교해 보시도록, 찾은 곳 0곳·40곳 이상 같은 이상한 경우는 ‘확인 필요’로 모읍니다.
- **예상 시간은 가정값**입니다(BiRefNet 30초/장 + 2차 30초). 남은 시간은 처리하면서 실제 평균으로 바뀝니다.
- **최종 확정은 상품 단위**입니다. 상품 중간에 멈추면 그 상품의 끝난 컷도 ‘완료’로 바뀌지 않습니다(이어서 하면 끝난 단계는 건너뛰고 확정만 함).
- 같은 사진의 누끼·찾기 결과 재사용(추가 비용 없음)은 **화면을 새로 고치기 전까지만** 됩니다. 새로 고친 뒤에는 진행 상태로 끝난 단계를 건너뛰므로 다시 부르지는 않습니다.
- 자동 보정 중에는 편집 화면이 잠깁니다. 진행 상태는 이 PC의 브라우저에만 저장됩니다.
- 1차 누끼는 무료 BiRefNet으로 고정했습니다(상품 설정이 Photoroom이어도). 유료는 위 옵션을 켰을 때만 씁니다.
