# 보고서 004-후속 — 소프트 무드를 기본으로, 휴대폰 가독성

- 브랜치: `claude/integration-002` (004 위에 이어서)
- 작성일: 2026-11-23
- PR은 만들지 않았습니다. stand.js·colorMatch.js·matte.js·CutRow.jsx는 건드리지 않았습니다. 쇼피 코드도 바꾸지 않았습니다.

## ① 무엇이 되는지 (화면에서 해 볼 방법)

1. **새 상품은 소프트 무드로 시작합니다.** ‘+ 새 상품’을 누르면 디자인 테마가 ‘소프트 무드’로 되어 있습니다. 처음 앱을 열 때, 마지막 상품을 지운 뒤, ‘사진 한꺼번에 올리기’로 상품이 만들어질 때도 같습니다.
   - 이미 저장된 상품 중 테마 정보가 없는 것은 지금처럼 **‘기본’**으로 열립니다. 이미 만든 상세페이지는 바뀌지 않습니다.
   - 테마 목록 순서: 소프트 무드 → 미니멀 화이트 → 매거진 → 기본.
2. **휴대폰에서 읽기 좋게 글자를 키우고 진하게 했습니다(소프트·미니멀).** 분위기(웜 베이지, 둥근 카드, 분홍빛 소제목)는 유지했습니다.
3. **줄바꿈을 띄어쓰기 단위로 바꿨습니다.** 글자를 키우자 “니트입 / 니다”처럼 낱말 중간에서 줄이 바뀌어서, 낱말 단위로 넘기도록 고쳤습니다. 한 줄보다 긴 낱말만 글자 단위로 끊습니다. 새 테마에만 적용되고 ‘기본’ 테마는 그대로입니다.
4. HTML 출력도 폰에서 PNG와 같은 크기로 보이도록 했습니다. 860px 화면에서는 PNG와 같은 크기이고, 더 좁은 화면에서는 같은 비율로 줄어듭니다.

### 색과 명암비 (WCAG 상대 휘도 공식, 4.5:1 이상 목표)

| 테마 | 글자 | 전 색 → 명암비 | 후 색 → 명암비 |
|---|---|---|---|
| 소프트 | 제목 | #4a3f38 → 8.94 (바탕) | 그대로 |
| 소프트 | 본문 | #6e5f55 → 5.37 / 카드 6.12 / 표 머리 4.94 | **#5c4d43 → 7.09 / 8.08 / 6.52** |
| 소프트 | 메모·컷 이름·상품 정보 | #a08b7c → **2.84** / 3.24 / 2.61 | **#765f50 → 5.23 / 5.96 / 4.81** |
| 소프트 | 소제목 알약(흰 글자 / 바탕색) | #c4927a → **2.71** | **#a45f66 (더스티 로즈) → 4.76** |
| 미니멀 | 본문 | #5a5a5a → 6.90 | **#444444 → 9.74** |
| 미니멀 | 메모·컷 이름 | #9a9a9a → **2.81** | **#6b6b6b → 5.33** |

- 바탕은 다음과 같습니다. 소프트는 #f6efe7(베이지), 사진·표 카드는 #ffffff, 표 머리글은 #f4e4d8입니다. 미니멀은 #ffffff입니다.
- 소프트의 모든 글자색은 세 바탕 모두에서 4.5:1을 넘습니다. 가장 낮은 경우가 메모 글자가 표 머리글 바탕에 놓일 때로 4.81입니다.
- 소제목 알약은 흰 글자를 4.5:1 이상으로 읽히게 하려고, 테라코타(#c4927a)에서 조금 더 분홍빛이 도는 짙은 더스티 로즈(#a45f66)로 바꿨습니다.

**검사 하나가 가끔 실패하는 문제(기존부터 있던 것)**
- `tests/studio-browser.mjs`는 이번 세션 초반에 가끔 실패했습니다. 바꾸기 전 커밋(cded236)으로 돌려도 6번 중 2~3번 실패해서 실패 비율은 같았습니다.

## ③ 아직 안 된 것·위험한 점

1. 치수 실루엣 그림 안의 글자(“A 가슴단면 · B 총장”)는 그림의 일부라 이번에 키우지 않았습니다. 폰에서는 작게 보입니다. 바로 아래 치수표가 커져서 읽는 데 문제는 적지만, 키우려면 실루엣 그림 쪽을 고쳐야 합니다(모든 테마와 쇼피 사이즈표에 영향).
2. 글자가 커져서 상세페이지 PNG가 조금 길어졌습니다. 소프트 합성 상품 기준으로 6,770px → 7,114px입니다. 사진이 아주 많으면 30,000px 한도에 더 빨리 닿을 수 있습니다(한도를 넘으면 HTML 저장 안내).
3. 소제목 색이 테라코타 → 더스티 로즈로 조금 진하고 분홍빛이 강해졌습니다. 명암비 때문에 바꾼 것입니다. 더 밝은 색을 원하시면, 대신 연분홍 바탕에 짙은 글자를 쓰는 방식도 가능합니다.
4. 매거진 테마는 이번 범위가 아니라 크기를 바꾸지 않았습니다(본문 17px, 폰 약 7.7px). 필요하면 같은 기준으로 맞추겠습니다.
5. 실제 상품 사진으로는 아직 보지 않았습니다.
