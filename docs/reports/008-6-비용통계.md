# 지시서 008-6 보고 — 유료 API 비용 기록·통계

작성: 2026-11-24 · 브랜치 `claude/integration-002`

사장님 결정에 따라 ‘수정할 곳 찾기’ 기본 민감도는 **적극 그대로** 두었습니다. 대신 유료 API를 부를 때마다 비용을 한 줄씩 기록하고 통계를 보여 줍니다.

## ① 무엇이 되는지 (화면에서 해 볼 방법)

1. 앱 위쪽 ‘사용 도구·비용’ 바로 아래에 **‘비용 통계’** 줄이 생겼습니다. 접혀 있어도 `오늘 $… · 이번 달 $… (…원)`이 보입니다.
2. 사진을 누끼·보정하거나(Photoroom), ‘🤖 수정할 곳 자동 찾기’, ‘사진 한꺼번에 올리기’를 누를 때마다 기록이 한 줄 생깁니다. ‘비용 통계’를 펼치면 다음이 보입니다.
   - 오늘 / 이번 주(월요일부터) / 이번 달 합계: 달러와 원화
   - 기능별 합계(수정할 곳 찾기 / 자동 분류 / 기타)와 **사진당 평균**
   - 수정할 곳 찾기 **민감도별** 합계와 **$1당 찾은 곳 수**
   - 최근 30일 하루 막대
   - 최근 기록 30줄: 시각·상품·컷·기능·모델·민감도·호출 수·토큰·비용·찾은 상자·재사용
   - **CSV 다운로드** 버튼
3. **환율** 칸의 기본값은 1,400원(가정)이고, 바꾸면 원화 금액이 바로 다시 계산됩니다.
4. **월 예산(원)** 칸의 기본값은 **50,000원**입니다(사장님 결정, 2026-11-24 추가). 화면에서 바꿀 수 있고, 칸을 비우면 경고가 꺼집니다.
   - 이번 달 사용액이 예산의 80%를 넘으면 노란 경고가 뜹니다.
   - 100%를 넘으면 빨간 경고와 **‘민감도를 보통으로 낮추기’** 버튼이 나옵니다. 누르면 수정할 곳 찾기가 사진당 1회 호출로 바뀝니다.
   - 어느 경우에도 호출을 자동으로 막지는 않습니다.
5. 같은 사진을 다시 써서 돈이 들지 않은 경우는 **‘재사용’ · $0**으로 남습니다.
6. 기록은 이 브라우저에 저장되고 **상품을 지워도 남습니다**.
   - 구글 드라이브를 연결하면 작업 폴더에 **`두손_앱_비용기록.csv`**를 만들고, 그 뒤로 계속 덧붙입니다.
   - 연결 전에 쌓인 기록은 연결하는 순간 한꺼번에 올라갑니다.
   - CSV 열 이름은 영문으로 고정했습니다: `timestamp, product, cut, feature, model, sensitivity, calls, input_tokens, output_tokens, cost_usd, boxes, cached`

### 금액 계산 방법
- **Claude**: 서버가 Claude 응답의 실제 토큰 수(입력·출력·캐시)를 그대로 돌려주고, 브라우저가 단가표로 계산합니다.
  - 단가는 `src/utils/pricing.js` 한 파일에 출처와 함께 둡니다.
  - Claude Opus 5.5 단가(100만 토큰당, 공식 가격표 <https://platform.claude.com/docs/en/about-claude/pricing>, 2026-11-24 직접 확인):

    | 입력 | 캐시 쓰기(5분) | 캐시 쓰기(1시간) | 캐시 읽기 | 출력 |
    |---|---|---|---|---|
    | $4 | $5 | $8 | $0.20 | $20 |

- **Photoroom**: 호출 1번에 $0.10이고, 남은 이미지가 5 줄어듭니다.
  - ‘5 차감’은 공식 문서(docs.photoroom.com/getting-started/pricing)에서 확인했습니다: 편집 1회 = 배경 제거 5회분.
  - **$0.10이라는 금액은 지시서·CLAUDE.md 기준입니다.** Photoroom 가격 페이지(www.photoroom.com/api/pricing)는 작업 환경에서 열리지 않아 이번에 다시 확인하지 못했습니다.
- **OpenAI**(상품 문구·쇼피 문구·OpenAI 보정): 공식 가격 페이지가 작업 환경에서 열리지 않아 단가를 **미확인**으로 두었습니다.
  - 토큰 수만 기록하고 비용 칸은 비워 둡니다.
  - 화면에는 ‘단가 미확인 n건 제외’로 표시합니다.
- **버튼 옆 예상 비용도 단가표로 다시 계산했습니다.** 토큰 가정은 사진 크기 기준(가로×세로÷750)이고, pricing.js에 적어 두었습니다.

  | 항목 | 예전 표시 | 지금 |
  |---|---|---|
  | 수정할 곳 찾기 1회 | 약 $0.02~0.05 | **약 $0.01~0.04** |
  | 적극(4회) | 약 $0.08~0.20 | **약 $0.04~0.16** |
  | 최대(9회) | 약 $0.18~0.45 | **약 $0.09~0.36** |
  | 자동 분류 1회 | 약 $0.05~0.15 | **약 $0.02~0.09** |

  실제 금액은 이제 ‘비용 통계’의 사진당 평균으로 확인하실 수 있습니다.

## ③ 아직 안 된 것·위험한 점

- **실제 Claude·Photoroom 호출로는 확인하지 않았습니다**(지시대로 모의 응답만 사용). 실제 응답의 토큰 수가 예상 범위 안에 드는지는 사장님이 처음 몇 번 쓰신 뒤 비용 통계에서 보입니다.
- **Photoroom $0.10, OpenAI 단가**는 위에 적은 대로 이번에 공식 페이지로 다시 확인하지 못했습니다. 확인되면 `src/utils/pricing.js`의 숫자만 고치면 됩니다.
- 앱의 기록은 **추정치**입니다. 실제 청구 금액은 Claude Console·Photoroom 대시보드가 기준입니다.
  - Claude가 안전 거절로 다른 모델로 다시 시도한 경우: 응답에 적힌 모델의 단가로 계산합니다. 단가표에 없는 모델이면 ‘미확인’으로 남깁니다.
  - 서버나 네트워크 오류로 응답을 받지 못한 호출은 기록되지 않습니다. Photoroom은 오류 난 호출에 이미지를 차감하지 않는다고 문서에 적혀 있습니다.
- **기록은 이 브라우저(이 PC의 크롬)에만 저장됩니다.**
  - 다른 PC에서 쓴 기록은 그 PC의 화면에만 보입니다. 같은 구글 드라이브 폴더를 연결하면 CSV 파일 하나로 모입니다.
  - 두 PC에서 **정확히 같은 순간**에 올리면 한쪽 줄이 빠질 수 있습니다(드라이브에 ‘덧붙이기’ 기능이 없어, 파일을 읽고 줄을 붙여 다시 올리는 방식이기 때문).
- 브라우저 데이터를 지우면 이 PC의 기록도 지워집니다. 드라이브에 올라간 CSV는 남습니다.
- **AI 모델컷 탭(FASHN)**은 이번 지시 범위(Claude·Photoroom·OpenAI)가 아니고 단가도 미확인이라 기록하지 않습니다.
- 월 예산은 **원화** 기준으로 정했습니다(환율 설정으로 달러 사용액을 원으로 바꿔 비교).
