# 015 — 옷걸이 v2 상세페이지 '두손 베이직'

- 기준 브랜치: `claude/hanger-v2`(821a924). 작업 브랜치: `claude/integration-002`.
- 참고 사이트에서는 **구성 방식만** 가져왔습니다. 사진·문구·로고는 쓰지 않았습니다. 시안은 합성 상품(그림으로 그린 가디건 2색)으로 만들었습니다.
- 유료 호출: **0회**. 분류·누끼는 모두 모의 응답입니다.

## 1. 무엇이 되나

| 지시 | 결과 |
|---|---|
| 새 테마 '두손 베이직'을 detailThemes에 추가, v2 새 상품 기본값 | `THEMES.dooson`. 옷걸이 v2에서는 목록 맨 앞이고 새 상품의 기본값입니다. `?v1`(마네킹)은 예전 목록과 기본값(소프트)을 그대로 씁니다. 소프트·미니멀·매거진·기본은 바꾸지 않았습니다. 예전 상품은 저장된 테마로 열립니다. |
| 상단: DOOSON, 상품명, 소개 한 줄 | DOOSON(자간을 넓힌 대문자), ‘상품 제목’(비면 상품 이름), ‘소개 한 줄’(비면 생략) |
| 정면(크게) → 후면 | 둘 다 가로를 꽉 채웁니다. 후면에는 소제목을 달지 않았습니다. |

| 연결 방식(가장 작은 변경) | 상품에 `data.colorGroup` 값 하나를 둡니다. ‘다른 상품 연결’을 하면 양쪽 상품에 같은 값이 저장됩니다. 연결된 상품의 정면 최종본(`slots.hero.image`)을 긴 변 720px JPG로 줄여서 씁니다. |
| 자동 분류 제안 | 옷걸이 v2 분류가 옷마다 `design`(같은 디자인 다른 색이면 같은 값)과 `color`(한국어 색 이름)도 돌려줍니다. 같은 분류 호출 안에서 받으므로 호출이 늘지 않습니다. 같은 디자인으로 본 상품은 노란 ‘연결 제안’ 상자에만 보이고, **사장님이 ‘연결’을 눌러야 연결됩니다**. 색 이름 칸에는 분류값이 미리 채워집니다. |
| DETAIL | 자동 디테일컷이 넥라인 → 소재 → 단추·여밈 → 밑단 → 소매 끝 순서로 이어집니다. 사진 설명은 넣지 않았습니다. |
| SIZE | 기존 치수 실루엣 그림(글자 키운 판)과 사이즈표가 들어갑니다. 빈칸은 ‘—’입니다. |
| INFO | 소재·세탁·핏 짧은 표입니다. **입력한 줄만** 나오고, 모두 비면 INFO가 없습니다. 앱이 내용을 만들지 않습니다. |
| AI 모델 컷 자리 | INFO 다음 자리에 꺼진 채로 둡니다(`MODEL_CUT_V2.enabled=false`). |
| 디자인 | 흰 바탕, 넓은 여백(860px 기준 좌우 80px), Noto Sans KR 300·400·500, 영문 대문자 소제목(자간 8px), 둥근 카드 없음입니다. |

**화면에서 해 보는 법**

1. 옷걸이 사진을 ‘사진 한꺼번에 올리기’로 올립니다(같은 디자인 2색 이상).
2. 상품마다 ‘사진 일괄 누끼·보정’과 ‘디테일컷 자동 만들기’를 누릅니다.
3. 아무 상품이나 열고, ‘두손 베이직 · 상단 · 색상 · 정보’ 칸에서 다음을 합니다.
   - 제안된 다른 색상을 확인한 뒤 ‘연결’을 누릅니다(또는 ‘다른 상품 연결’에서 직접 고릅니다).
   - 소개 한 줄, 영문 문구, 소재·세탁·핏을 입력합니다(비우면 빠집니다).
4. ‘전체 미리보기’를 누릅니다.

## 3. 아직 안 된 것·위험한 점

- **실제 사진으로는 실행해 보지 않았습니다.** 시안은 그림으로 그린 가디건입니다. 실제 옷걸이 사진에서의 느낌(사진이 가로를 꽉 채울 때 여백, 디테일컷 연속 5장의 길이)은 사장님 확인이 필요합니다.
- **발견(014 범위, 고치지 않음)**: 시험용 네이비 가디건(어두운 옷 + 밝은 단추)에서 단추 찾기가 단추를 놓쳐 ‘단추·여밈’ 디테일컷이 빠졌습니다. 같은 그림의 아이보리는 찾았습니다. 합성 그림에서만 확인했고 실제 사진에서는 확인하지 않았습니다. 지시 범위를 넘어 손대지 않았습니다.
- 자동 분류의 디자인 묶음 제안은 실제 Claude로 시험하지 않았습니다(모의만). 같은 디자인의 다른 색을 실제로 잘 묶는지는 모릅니다. 비교는 같은 올리기(드라이브는 같은 분류 묶음 20장) 안에서만 합니다.
- 두손 베이직에는 ‘상품 설명’(긴 글, OpenAI 문구)과 ‘상품 정보’ 칸이 들어가지 않습니다. 지시서의 ‘짧은 소개 한 줄’ 구성을 따랐습니다. 필요하면 다시 넣겠습니다.
- COLOR CHOICE에 쓰는 사진은 연결된 상품에 저장된 **정면 최종본**입니다. 그 상품을 다시 보정하면 다음 미리보기·저장 때 바뀐 사진이 들어갑니다. 정면이 없는 색은 빠집니다.
- 연결 정보는 이 브라우저의 상품 저장소(상품 데이터의 `colorGroup`)에 있습니다. 드라이브 저장·다른 PC에서 불러오기로 연결이 유지되는지는 실행해 보지 않았습니다.
