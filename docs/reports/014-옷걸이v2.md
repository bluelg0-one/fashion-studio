- 브랜치: `claude/integration-002`. `claude/hanger-v2`(acb495a)를 빨리 감기(fast-forward)로 맞춘 뒤 작업했습니다(강제 push 없음). nice-bohr·archive 브랜치는 건드리지 않았습니다.
- 유료 호출 0회입니다. Claude·Photoroom·드라이브 응답은 모두 모의입니다. 상품 사진은 커밋하지 않았습니다(검사는 합성 그림).

## 1단계 — 옷걸이 v2 기능

### ① 무엇이 되는지 (화면에서 해 볼 방법)
1. **컷 구성**: 앱을 열면 컷 칸이 '옷걸이 정면'·'옷걸이 후면' 2개만 보입니다.
   - 숨긴 것: 측면·확대 칸, '+ 컷 추가', Fit guide, 'AI모델컷' 탭, 받침대 기둥·마네킹 꼭지·자동 수평 옵션, Photoroom 생성형 편집.
   - 옷걸이는 기본으로 남기고, 흰 옷 맑게는 켜져 있습니다.
   - 예전 마네킹 화면은 주소 끝에 `?v1`을 붙이면 그대로 열립니다(지운 코드 없음).
2. **자동 분류**: '사진 한꺼번에 올리기'나 드라이브 가져오기를 하면 옷별로 묶고 정면/후면만 판별합니다.
   - 정면은 '옷걸이 정면' 칸, 후면은 '옷걸이 후면' 칸에 들어갑니다.
   - 애매한 사진이나 같은 쪽 사진이 2장이면 '확인 필요'로 남습니다.
3. **디테일컷 자동 생성**: 정면(·후면)을 누끼·보정한 뒤 '디테일컷 자동 만들기'를 누릅니다.
   - 긴팔 기준 넥라인·소재(후면에서)·단추·여밈·밑단·소매 끝이 실제 사진에서 잘려 나옵니다.
   - 원본 기준 긴 변 800px이 안 되는 것은 키우지 않고 '해상도 부족'으로 빠집니다.
   - 단추를 못 찾았거나 소매가 몸판에 붙은 경우는 '위치 확인 필요'로 빠집니다.
   - '확신 없는 위치는 Claude로 찾기'(유료, 기본 꺼짐)를 켜면, 상품당 한 번만 Claude에게 위치를 묻습니다.
   - 디테일컷마다 '상세페이지에 포함'을 끌 수 있고, 상품을 다시 열어도 남습니다.
4. **자동 보정**('자동 보정' 판): 정면·후면 → 1차 → 색감 통일 → 2차(013 방식, 회전 없음) → 디테일컷 → 최종 순서로 돕니다.
5. **상세페이지**('전체 미리보기', 소프트 테마): 옷걸이 정면 → 제목·설명 → Back(후면) → Detail(디테일컷) → Size 순서입니다.
6. **모델컷**: 만들지 않았습니다. 상세페이지에 'AI 모델 컷' 자리만 두었고, 꺼져 있어 아무것도 나오지 않습니다.

### ③ 아직 안 된 것·위험한 점
- **실제 옷걸이 사진으로는 확인하지 못했습니다.** 디테일 위치는 합성 사진에서만 맞는 것을 봤습니다. 실제 옷의 넥라인 높이, 단추 찾기, 소매 끝 찾기는 사진을 받아야 확인할 수 있습니다.
- **해상도 문제**: 앱은 사진을 긴 변 2400px로 줄여 받습니다. 그래서 옷걸이 전체 사진에서 원단을 800px 이상으로 자르면 화면의 절반 이상이 되어, 소재 컷이 '해상도 부족'으로 자주 빠질 수 있습니다.
  - 해결하려면 디테일 자르기용으로 원본을 더 크게(예: 4000px) 보관해야 합니다.
  - 저장 공간이 늘어나므로 사장님 결정 후 진행하겠습니다.
- **분류 지시문**: 실제 Claude로 정면/후면 판별을 시험하지 않았습니다(유료 금지). 무늬 없는 니트처럼 앞뒤가 비슷한 옷은 '확인 필요'가 많이 나올 수 있습니다.
- **디테일컷 다시 만들기**: 정면·후면을 다시 보정한 뒤 디테일컷이 저절로 다시 만들어지지는 않습니다. 직접 보정했다면 '디테일컷 다시 만들기'를 눌러야 합니다(자동 보정은 매번 다시 만듭니다).

### ④ 사장님이 해 주셔야 할 일
1. 옷걸이 정면·후면 **실제 사진 몇 벌**(단추 있는 옷 1벌, 없는 옷 1벌, 바지 1벌)을 채팅에 올려 주세요. 디테일 위치를 실제 사진으로 확인하겠습니다.
2. 원본을 더 크게 보관할지(소재 컷 해상도용) 정해 주세요.
3. 상세페이지 참고 사이트 주소와 캡처를 팀장에게 주세요(새 디자인 기획용).

## 2단계 — 검증 구조

### ① 무엇이 되는지 (화면에서 해 볼 방법)
1. **검증 기준서**: `docs/qa/검증기준서.md`
   - 자동 측정 항목과 기준값: 색 변화, 정면·후면 색 차이, 회색 얼룩, 단추 수 변화 0, 옷걸이 고리 유지, 가장자리 잘림, 배경 잔여물, 옷 면적, 채널별 해상도, 디테일 위치.
   - 눈으로 볼 항목(실물과 같은지, 하자 숨김, 가장자리 품질 등)은 따로 표로 나눴습니다.
2. **자동 점검**: 자동 보정이 상품 하나를 끝내면 저절로 점검합니다.
   - 자동 보정 판에 '자동 점검 · 통과 n · 보류 n · 불합격 n' 표가 나옵니다. 상품별 결과·다시 편집 횟수·이유가 함께 보입니다.
   - 편집 화면의 '자동 점검' 칸에서 '이 상품 자동 점검'(무료)을 눌러도 됩니다. 결과 상자와 항목별 표가 나옵니다.
3. **자동 다시 편집(최대 2회)**: 보류·불합격 중 설정으로 고칠 수 있는 것만 다시 합니다.
   - 2차가 색·회색·단추를 망쳤으면: 1회는 '그림자 펴기만'(Claude 추가 호출 없음), 2회는 '2차 없이 1차를 최종으로'.
   - 고리가 사라졌으면: '떨어진 조각 지우기'를 끄고 1차를 다시 합니다.
   - 정면·후면 색 차이가 크면: 색감을 강도 100%로 맞춥니다.
   - 그래도 안 되거나 고칠 수 없는 항목이면 **'사장님 확인 필요'**로 남깁니다. 그 상품의 상세페이지는 초안으로 저장됩니다. 고칠 수 없는 항목은 가장자리 잘림·떨어진 조각(끈·벨트일 수 있음)·해상도·디테일 위치입니다.
4. **점검보고서**: 완성본 저장 때 드라이브 상품 폴더에 `점검보고서.csv`가 함께 올라갑니다. 열(영문 고정):
   `product_id, product_name, checked_at, product_status, attempts, owner_review, cut, check, result, value, limit, reason` (한 줄 = 점검 항목 하나, 항목 이름은 기준서 표의 영문 이름)

### ③ 아직 안 된 것·위험한 점
- **기준값은 합성 사진으로만 정했습니다.** 실제 옷걸이 사진에서 보류·불합격이 너무 많거나 적을 수 있습니다. 실제 사진 몇 벌로 한 번 맞춰야 합니다.
  - 특히 '떨어진 조각'은 소매가 몸판과 떨어져 보이는 옷에서 보류가 날 수 있습니다.
  - '자사몰 해상도'는 2400px 사진에서 자주 보류가 날 수 있습니다.
- 단추 찾기는 사진 한 장에 약 2초가 걸립니다. 그래서 2차가 고친 범위에서만 찾습니다. 2차가 사진 전체를 바꾸는 경우(Photoroom 유료 다림질)에는 더 오래 걸립니다.
- 점검보고서 CSV가 실제 드라이브에 올라가는지는 확인하지 못했습니다(드라이브 모의 검사는 예전부터 실패하는 `studio-drive`, 실제 드라이브 호출 금지). 만드는 부분은 검사했고, 올리는 부분은 기존 완성본 파일과 같은 길을 씁니다.
- 다시 편집에서 1차를 다시 하면, 2차의 수정할 곳 찾기도 다시 해서 Claude 비용이 듭니다(상품당 최대 2회 × 4타일). 비용 기록에는 남습니다.
