## ③ 충돌 해결에서 내린 판단과 남은 위험

충돌 해결 원칙: 충돌 난 파일은 모두 **nice-bohr(현재) 쪽을 그대로 두고** 인스타 관련 줄만 다시 넣었습니다.

- `src/components/AutoStudio.jsx`: 현재 쪽의 IOPaint·BiRefNet·사진 틀(frame)·`migrateSlots`·`sanitizeRetouch`·로컬 저장 시각을 그대로 두었습니다. 인스타 브랜치에 있던 예전 `autoMatch` 상태와 예전 `studioImages` 불러오기 줄은 넣지 않았습니다. 넣은 것은 다음 다섯 가지뿐입니다: `instagram` 상태, 상품 저장(snapshot)·불러오기·자동 저장 대상에 `instagram` 추가, `InstagramPanel` 불러오기, 쇼피 패널 밑에 06 패널 배치.
- `src/components/AutoStudio.css`: 현재 쪽 전체를 두고, 끝에 `.instagram-*` 스타일 9줄을 붙였습니다.
- `.env.example`: 현재 쪽 전체 + 인스타 변수 3개(`INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_POST_PASSWORD`, `BLOB_READ_WRITE_TOKEN`).
- `package.json`: 현재 쪽(`@anthropic-ai/sdk`, `zod`, `sync:iopaint`) + `@vercel/blob`.
- `vite.config.js`: 로컬 변수 접두사를 `ANTHROPIC_`까지 포함하도록 유지하고 `INSTAGRAM_`, `BLOB_`를 더했습니다. 인스타 서버 경로도 연결했습니다.
- `vercel.json`: `api/modelshot.js`(60초)와 `api/instagram.js`(120초) 둘 다 남겼습니다.
- 인스타 사진 순서는 `shopeePhotos()`를 다시 씁니다. 현재 쪽에도 이 함수가 같은 형태로 있어서 그대로 이어지는 것을 브라우저 검사로 확인했습니다.

남은 위험·판단이 필요한 점:
1. **`@vercel/blob` 패키지와 Vercel Blob 저장소.** 인스타 브랜치에 원래 들어 있던 것을 그대로 가져왔습니다. 지시서에는 ‘새 패키지 도입 금지’가 있지만, 인스타 직접 게시는 사진이 공개 주소에 있어야 해서 이것 없이는 동작하지 않습니다. 그래서 빼지 않았습니다. Vercel Blob은 무료 한도를 넘으면 요금이 생길 수 있는 서비스입니다(사진은 게시 직후 지우는 구조). 계속 쓸지 사장님 결정이 필요합니다. 쓰지 않기로 하면 ZIP 다운로드와 캡션 복사는 그대로 쓸 수 있습니다.
2. **AI모델컷의 비용 표시가 CLAUDE.md 규칙에 못 미칩니다.** 생성 버튼에 금액 표시와 확인 창이 없습니다(다른 기능에는 ‘Photoroom · $0.10/장’ 같은 표시가 있음). 얼굴 고정 시 크레딧이 추가된다는 문구만 있습니다. FASHN 장당 단가를 확인하지 못해서 금액을 임의로 넣지 않았습니다. 이번 지시 범위(통합)를 넘는 일이라 고치지 않았고, 다음 작업으로 제안합니다.
3. **AI모델컷 결과를 원본과 나란히 보는 화면이 없습니다.** CLAUDE.md의 ‘생성형 AI 결과는 원본과 비교’ 규칙과 관련된 부분이라, 위 2번과 함께 다음 작업으로 제안합니다.
4. AI모델컷의 ‘FASHN 연결됨’ 표시는 키가 실제로 있는지와 상관없이 항상 나옵니다. 키가 없으면 생성할 때 오류 문구가 뜹니다.
5. `/api/modelshot`은 Vercel에서만 동작합니다. 로컬 `npm run dev`·`npm start`에는 이 경로가 연결돼 있지 않습니다(통합 전 원래 브랜치도 같음). README에 적어 두었습니다.
6. 인스타 직접 게시와 FASHN은 실제 계정·키로 시험하지 않았습니다.
7. 의존성 잠금 파일(lockfile)이 여전히 없습니다. 패키지 버전이 설치할 때마다 달라질 수 있습니다.
