## ① 무엇이 되는지 (화면에서 해 볼 방법)

화면 위쪽 **AI모델컷** 탭에서 확인합니다.

1. **비용 표시와 확인 창**
   - 생성 버튼 글자가 **‘FASHN 유료 · N장 생성’**으로 바뀌었습니다. 버튼 아래에는 ‘FASHN 크레딧 차감(단가 미확인) · 얼굴 고정은 장당 크레딧 추가 · 같은 설정은 다시 누르면 저장된 결과 재사용’ 문구가 나옵니다.
   - 버튼을 누르면 확인 창이 뜹니다. 확인 창에는 새로 만들 장수(장면 수 × 장수), 비용 문구, 얼굴 고정 여부(고정하면 장당 크레딧 추가), 배경 사진 사용 여부, 재사용·건너뛸 장면 수가 나옵니다. **취소하면 아무것도 호출하지 않습니다.**
   - ‘모델 후보 2명 생성’ 버튼도 유료라서 같은 비용 문구와 확인 창을 붙였습니다(지시서는 생성 버튼만 말했지만 같은 규칙을 적용했습니다).
2. **같은 설정은 다시 호출하지 않음**
   - 아래 조건이 모두 같으면 다시 눌러도 FASHN을 부르지 않습니다: 옷 사진, 내 모델, 장면, 추가 요청, 비율, 장면당 장수, 배경 사진.
   - 대신 저장된 결과를 다시 보여 주고 **‘저장된 결과 재사용 · 추가 비용 없음’** 표시를 붙입니다. 이때는 확인 창도 뜨지 않습니다.
   - 저장된 결과는 이 브라우저에 70시간 동안 남습니다. FASHN 결과 주소가 약 3일 뒤 만료되기 때문입니다. 새로고침해도 재사용됩니다.
   - 같은 설정이 지금 만들어지는 중이면 그 장면은 건너뜁니다. ‘다시 시도’를 누를 때도 저장된 결과가 있으면 그것을 씁니다.
   - 설정을 하나라도 바꾸면(예: 장면당 1장 → 2장) 새로 호출하고 확인 창이 뜹니다.
3. **원본과 나란히 보기**
   - 결과 카드마다 원본 썸네일이 들어간 **‘원본과 나란히 보기’** 버튼이 있습니다.
   - 누르면 왼쪽에 원본 의류 사진, 오른쪽에 ‘AI 생성 결과(실제 착용 사진 아님)’를 크게 나란히 보여 줍니다. 아래에는 ‘색·무늬·소재감·핏·하자가 원본과 다르면 판매 사진으로 쓰지 마세요’ 안내가 붙습니다. Esc 키나 바깥 클릭으로 닫힙니다.
4. **실제 연결 상태 표시**
   - 탭을 열면 서버에 키가 있는지만 확인하는 가벼운 경로(`/api/modelshot`, `action: 'config'`)를 부릅니다. FASHN을 호출하지 않으므로 과금이 없습니다. 응답은 `{fashn: true/false, styleroom: true/false}`뿐이고 키 값은 넣지 않습니다.
   - FASHN 칸 표시는 상태에 따라 ‘연결 확인 중…’, ‘키 설정됨 · 유료’, ‘키 없음 (서버 설정 필요)’, ‘연결 상태 확인 실패’ 중 하나로 나옵니다.
   - 키가 없으면 생성 버튼과 모델 후보 버튼이 꺼지고 ‘서버에 FASHN_API_KEY가 없어 생성할 수 없습니다’ 안내가 나옵니다.

### FASHN 단가를 확인하지 못한 이유
- 작업 환경에서 `docs.fashn.ai`와 `fashn.ai`에 접속이 막혀 있어(DNS 차단) 공식 문서를 직접 읽지 못했습니다. 그래서 지시대로 금액 대신 **‘FASHN 크레딧 차감(단가 미확인)’**으로 표시했습니다.
- 참고로, 웹 검색 결과 요약에는 아래 내용이 나왔습니다. **페이지를 직접 열어 확인한 것은 아니므로 화면에는 넣지 않았습니다.**
  - API 크레딧 1개 $0.075(최소 100개 구매): [FASHN API Pricing](https://help.fashn.ai/plans-and-pricing/api-pricing)
  - product-to-model은 생성 모드·해상도에 따라 장당 1~5 크레딧: [Product to Model](https://docs.fashn.ai/api-reference/product-to-model)
  - face_reference는 장당 +3 크레딧: [Product to Model](https://docs.fashn.ai/api-reference/product-to-model), [Face Reference](https://help.fashn.ai/using-fashn/guides/model-consistency/face-reference)
  - 12월 중순부터 +2 크레딧으로 바뀐다는 공지도 있음: [App and API Plans Are Merging](https://fashn.ai/blog/fashn-app-and-api-plans-are-merging)
- 이 앱은 생성 모드·해상도를 따로 지정하지 않습니다. 그래서 기본값이 무엇인지 확인해야 장당 금액을 정확히 적을 수 있습니다. 확인되면 `src/components/ModelCutStudio.jsx`의 `FASHN_COST_LABEL` 한 줄만 바꾸면 됩니다.

## ③ 아직 안 된 것·위험한 점

1. **장당 금액은 표시하지 못했습니다**(위 이유). 확인 창에는 ‘장수’만 정확하고, 금액은 ‘단가 미확인’입니다.
2. 재사용 판단에는 옷 사진을 줄여 만든 JPG가 쓰입니다. 같은 사진이라도 다른 브라우저나 다른 컴퓨터에서 줄이면 결과 파일이 조금 달라질 수 있습니다. 그러면 재사용되지 않고 새로 호출합니다(확인 창은 뜹니다). 재사용 기록은 브라우저마다 따로라서 다른 컴퓨터와 공유되지 않습니다.
3. 재사용 기록에는 결과 주소만 저장합니다. 70시간이 지나면 기록을 버립니다. 그 전에 FASHN 쪽에서 주소가 먼저 만료되면 이미지가 깨져 보일 수 있습니다. 그때는 설정을 조금 바꿔 다시 만들어야 합니다(이전과 같은 제한, 화면에 ‘3일 뒤 만료’ 안내 있음).
4. 로컬(`npm run dev`, `npm start`)에는 `/api/modelshot`이 연결돼 있지 않습니다. 그래서 ‘연결 상태 확인 실패’로 나오고 생성 버튼이 꺼집니다. 원래 로컬에서는 동작하지 않던 기능이라 동작 차이는 없고, 상태 표시만 정직해졌습니다.
5. 비교 보기의 ‘원본’은 모델컷 탭에서 고른 의류 사진(상세페이지 제작 탭의 완성 사진 또는 직접 올린 사진)입니다. 보정 전 촬영 원본이 아닙니다.
6. Vercel에는 아직 `FASHN_API_KEY`가 없습니다(002 보고서 ④-1). 그래서 미리보기 주소에서는 ‘키 없음’이 표시되고 버튼이 꺼진 상태일 것입니다. 미리보기 화면은 직접 열어 보지 못했습니다.
7. 쇼피 코드는 손대지 않았습니다(보류 지시).
