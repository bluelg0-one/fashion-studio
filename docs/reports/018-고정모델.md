# 018 — 모델컷 '고정 모델' 방식 (FASHN 가상 피팅 + 기본 모델 사진)

- 기준 브랜치: `claude/hanger-v2`(a0e514e). 작업 브랜치: `claude/integration-002`.
- 실제 FASHN·Google·드라이브 호출은 하지 않았습니다(모의 응답만). 유료 호출 0회입니다.

## 무엇이 되나

사장님 요청: "모델을 매번 새로 만들면 돈이 드니, 처음 한 번만 만들어 고정으로 쓰자."

- **기본 모델 사진 3칸**은 FASHN과 Google이 함께 씁니다. 017에서 Google용으로 만든 칸입니다.
  - 상반신(얼굴 없음) / 하반신 / 원피스. 반바지는 하반신 칸, 전신은 상반신 칸을 씁니다.
  - 모델컷 탭에서 엔진과 상관없이 늘 보입니다.
- **FASHN 방식 자동 선택**
  - 지금 구도의 기본 모델 사진이 있으면 **고정 모델**입니다. FASHN 가상 피팅(`tryon-v1.6`)으로 그 사람 사진에 옷을 입힙니다.
  - 없으면 지금처럼 **새 모델 생성**(`product-to-model`)입니다.
  - 엔진 칸에 '지금 방식: 고정 모델 · 장당 약 $0.075' 또는 '새 모델 생성'을 표시합니다. 확인 창과 생성 버튼('FASHN 고정 모델 유료 · N장 생성')에도 나옵니다.
- **고정 모델에서 쓰지 않는 것**
  - 얼굴 고정(추가 크레딧)을 쓰지 않습니다. 사람 사진이 이미 고정이기 때문입니다. '내 모델(얼굴 고정)' 칸도 숨깁니다.
  - 장면·문구·비율도 숨깁니다. 가상 피팅은 사람 사진의 배경·비율을 따릅니다.
- **기본 모델 사진 만드는 법**(이미 있는 버튼을 재사용)
  - 'AI로 새 모델 만들기' 후보 카드의 '기본 모델로 저장(구도)'
  - 모델컷 결과 카드의 '기본 모델로 저장'(FASHN·Google 결과 모두)
  - 칸을 눌러 직접 올리기
- **저장 위치**
  - 이 브라우저(localStorage)에 저장합니다.
  - 구글 드라이브가 연결돼 있으면 작업 폴더의 `두손_기본모델.json`에도 저장합니다(앱이 만든 파일만 쓰는 권한 안).
  - 모델컷 탭을 열 때 드라이브에 있으면 불러옵니다. 브라우저 저장본과 비교해 나중에 바꾼 쪽을 씁니다. 노트북과 집 PC가 같은 모델을 쓰게 하기 위해서입니다.
  - 저장·불러오기 결과는 칸 위에 표시합니다.
- 같은 설정 재사용, 비용 기록(장당 $0.075 추정), 원본 나란히 보기, '이 상품 모델컷으로 저장'(얼굴 자동 자르기)은 고정 모델에도 똑같이 적용됩니다.

## FASHN 가상 피팅 확인 내용

공식 문서(docs.fashn.ai)는 이 작업 환경에서 열리지 않았습니다(017과 같은 네트워크 제한). 아래는 **검색 결과 요약 기준이며, 원문은 미확인**입니다.

| 항목 | 내용 |
|---|---|
| 엔드포인트 | 기존과 같은 `POST /v1/run`, `model_name: 'tryon-v1.6'`(서버 허용 목록에 이미 있음, 서버 변경 없음) |
| 입력 | `model_image`(사람 사진), `garment_image`(옷 사진), `category`: `auto` / `tops` / `bottoms` / `one-pieces`. 앱이 쓰는 값: 상반신 `tops`, 하반신 `bottoms`, 원피스 `one-pieces`. 그 밖에 `num_samples`(1~4), `output_format: 'jpeg'` |
| 크레딧 | tryon-v1.6은 **장당 1크레딧**, 1크레딧 = $0.075 |
| 다른 엔드포인트 | `tryon-max`는 장당 2~5크레딧(모드·해상도에 따라)이라 비싸서 쓰지 않았습니다 |

- 옷 사진 종류(`garment_photo_type`)는 보내지 않았습니다(FASHN 기본값 자동 판별). 실제 결과가 나쁘면 'flat-lay' 지정을 시험해 볼 수 있습니다.

## 검사

  - 고정/새 모델 판단(구도별 칸, 반바지는 하반신 칸)
  - 가상 피팅 입력(category·장수 상한·얼굴 고정 없음)
  - 드라이브/브라우저 중 최신 선택
- `npm run build` 통과.
- 화면 검사 `studio-v2-tabs`(모의 API)에 고정 모델 단계를 추가했고 통과했습니다.
  - 상반신 기본 모델 사진을 넣으면 FASHN 방식 표시가 '고정 모델 · 장당 약 $0.075'로 바뀌고, 얼굴 고정 칸이 사라집니다.
  - 요청은 `tryon-v1.6`입니다. 기본 모델 사진과 옷이 들어가고, `tops`, 1장, 얼굴 고정·문구 없음입니다. 확인 창에 고정 모델 문구가 나옵니다.
  - 구도를 하반신(사진 없음)으로 바꾸면 '새 모델 생성'으로 돌아갑니다.
- `?v1` `studio-modelcut` 통과(예전 AI모델컷 탭은 바뀌지 않음).

## 아직 안 된 것·위험한 점

- **드라이브 저장·불러오기는 실제 드라이브로 실행해 보지 않았습니다.** 브라우저 검사에서는 드라이브 로그인을 흉내 낼 수 없어서, 최신 선택 계산만 검사했습니다.
  - 드라이브는 로그인('구글 드라이브 연결')한 뒤에만 동작합니다. 모델컷 탭을 연 다음에 로그인했다면 탭을 한 번 옮겼다 오면 불러옵니다.
- 실제 FASHN 가상 피팅 결과 품질(옷걸이 사진을 옷 사진으로 잘 인식하는지)은 모릅니다.
- 기본 모델 사진은 한 장당 수백 KB입니다. 드라이브 파일 하나에 3장을 함께 둡니다.

## 사장님이 해 주실 일

1. 모델컷 탭에서 구도별로 마음에 드는 모델을 한 번만 만들어 '기본 모델로 저장'을 눌러 주세요(상반신·하반신·원피스).
2. 구글 드라이브를 연결해 두시면 집 PC에서도 같은 모델이 불러와집니다.
3. 그 뒤 실제로 1장만 만들어 보시고, 결과를 알려 주세요.
