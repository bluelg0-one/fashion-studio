## ① 무엇이 되는지 (화면에서 해 볼 방법)

**상세페이지 제작** 탭 위쪽 도구줄(‘전체 미리보기’ 버튼 왼쪽)에 **‘디자인 테마’** 선택 칸이 생겼습니다. 테마를 고른 뒤 아래 세 버튼 중 하나를 누르면 같은 테마로 나옵니다.
- 전체 미리보기
- 상세페이지 전체 PNG 저장
- HTML 다운로드

| 테마 | 방향 |
|---|---|
| 기본 | 지금까지의 모양 그대로(예전 상품과 새 상품 모두 기본값) |
| 미니멀 화이트 | 넓은 여백, 얇은 세리프 제목, 영문 이탤릭 섹션 제목과 짧은 선, 무채색, 선만 있는 치수표 |
| 소프트 무드 | 웜 베이지 바탕, 사진을 흰 둥근 카드에, 테라코타색 알약 모양 섹션 제목, 둥근 카드 치수표 |
| 매거진 | 대표 사진을 가로 끝까지, “01 / Fit guide”처럼 번호와 굵은 영문 제목, 디테일 컷은 두 장씩 나란히 편집 배치, 검은 머리글 치수표 |

- 순서(대표 정면 → 문구 → Fit guide → Detail → Size)와 치수 실루엣·치수표는 모든 테마에서 그대로입니다.
- 고른 테마는 상품마다 저장되어 새로고침해도 유지됩니다. 테마 정보가 없는 예전 상품은 ‘기본’으로 열립니다.
- 시안 비교 이미지는 가짜 상품(합성 이미지, 실제 상품 사진 아님)으로 만들었습니다.
  - 한눈에 비교: `docs/reports/img/004-themes-compare.png` (왼쪽부터 기본, 미니멀, 소프트, 매거진. 절반 크기)
  - 전체 PNG(실제 저장 결과 그대로): `004-theme-basic.png`, `004-theme-minimal.png`, `004-theme-soft.png`, `004-theme-magazine.png`
  - 매거진은 디테일 4컷을 두 줄로 배치해서 길이가 가장 짧습니다.

### 글꼴과 라이선스

모든 글꼴은 Google Fonts에서 받습니다. 모두 **SIL Open Font License 1.1** 글꼴입니다. 이 라이선스는 무료로 상업적으로 쓸 수 있고, 글꼴을 이미지나 웹 문서에 넣어 판매 페이지로 써도 됩니다. 글꼴 파일 자체를 따로 파는 것만 금지됩니다.

| 글꼴 | 쓰는 곳 |
|---|---|
| Noto Serif KR | 미니멀 제목, 매거진 한글 제목 |
| Noto Sans KR | 미니멀·매거진 본문, 치수표 |
| Cormorant Garamond | 미니멀 영문 섹션 제목 |
| Gowun Batang | 소프트 제목, 섹션, 치수표 머리글 |
| Gowun Dodum | 소프트 본문 |
| Playfair Display | 매거진 영문 섹션 제목, 번호 |

- 새로 설치한 패키지는 없습니다. 글꼴은 Google Fonts 주소에서 그때그때 받습니다.
- **PNG에 글꼴이 실제로 들어가는지 확인했습니다.**
  - 한국어 글꼴은 글자 범위별로 나뉘어 있습니다. 처음에는 일부 글자만 받아서 몇몇 글자가 시스템 글꼴로 섞여 그려졌습니다. 지금은 문서에 쓰인 글자 전체를 받은 뒤 그리도록 고쳤습니다.
  - 자동 검사에서 글꼴 주소를 막고 그리면 PNG가 달라지고 화면에 안내가 뜹니다. 즉 평소 PNG에는 테마 글꼴이 실제로 들어갑니다.
- 글꼴을 받지 못하면(인터넷 끊김 등) 시스템 글꼴로 그리고, 안내 줄에 ‘테마 글꼴을 받지 못해 기본 글꼴로 그렸습니다’라고 표시합니다.

## ③ 아직 안 된 것·위험한 점

1. **실제 상품 사진으로는 아직 보지 않았습니다.** 시안은 합성 이미지 기준입니다. 실제 사진(배경색, 사진 비율)에 따라 인상이 달라질 수 있어서, 사진이 오면 같은 상품으로 다시 비교해 드리겠습니다.
2. 테마 PNG를 만들 때 인터넷이 필요합니다(글꼴 받기, 처음 한 번 몇 초). 끊겨 있으면 시스템 글꼴로 저장되고 안내가 뜹니다.
3. HTML 출력은 같은 색·글꼴·배치를 CSS로 그립니다.
   - 화면 폭에 맞게 줄어들기 때문에 PNG와 글자 줄바꿈 위치가 조금 다를 수 있습니다.
   - 글꼴은 Google Fonts 주소로 연결되어 있습니다. 스마트스토어 편집기처럼 외부 글꼴 연결을 지우는 곳에 HTML을 붙이면 시스템 글꼴로 보입니다. 판매 채널에는 PNG를 쓰시길 권합니다.
4. 매거진의 두 장 나란히 배치는 높이를 맞추려고 사진을 각 칸에 맞춰 줄입니다. 사진을 자르지는 않고, 남는 부분은 흰색입니다. 비율이 아주 다른 두 컷이 짝이 되면 한쪽이 작아 보일 수 있습니다.
5. 섹션 제목(Fit guide, Detail, Size)을 한글로 바꾸면 매거진·미니멀의 영문 글꼴 대신 한글 세리프 글꼴로 나옵니다. 깨지지는 않습니다.
6. 치수 실루엣 그림 안의 글자는 기존 그림 그대로(기본 글꼴)입니다.
7. 쇼피 영문 사이즈표 이미지는 테마와 상관없이 예전 모양 그대로입니다(쇼피 보류).
